# Daedalus
Toolbox for game design tools.
- **Athena**, the room explorer (generator, editor, solver, play mode). Usage: `athena/USAGE.md`. Tests: `npm test` or just access the git pages version.
- **Apollo**, music and sound effects (music maker, SFX generator, bindable/tunable keyboard, WAV export, CLI). Usage: `apollo/USAGE.md`.
