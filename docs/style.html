The visual rules every Daedalus tool follows. Tokens live in shared/base.css; each tool's style.css only adds its accent and layout. Athena is the reference build. This page loads base.css, so its samples show the live tokens.

Principles

  • Dark, flat, simple modern: Dark Material Dracula surfaces with Dracula accents.
  • No borders, no soft shadows, no gradients. Structure comes from fill steps between surfaces. Allowed exceptions: 1px --line splits between panes, and an inset 2-3px colored marker (selected state, mode marker).
  • The tool fills the window. Panes sit flush against each other; only items inside a pane are rounded.
  • One accent per tool (its icon color). Other Dracula colors carry meaning only: good / warn / bad, mute / solo, mode markers.
  • Simple / Full: secondary controls get class adv and hide under body.simple.

Layout

  • Header: 48px, --deep. Brand on the left: Daedalus icon 26px, 1px divider, tool icon 22px, tool name 15px bold. Toolbar buttons 32px high. File name and state on the right.
  • Panes: CSS grid with gap: 1px over a --line background (or box-shadow: inset 1px 0 0 var(--line)). No outer margin, no corners, no gap wider than 1px.
  • Surfaces: the main work area (canvas, editor) is --raised; side panes and docks are --base; tab strips are --deep.
  • Pane padding: 10px 14px. Section headers start each block, 14px above and 8px below.

Radius

Always a token, never a raw px value. Panes and the window get no radius.

--r-xs 2px
bars, tracks, notes, markers, meters
--r-sm 4px
chips, tags, cells, small square buttons, inline code
--r 6px
buttons, inputs, cards and rows inside panes, canvases
--r-lg 8px
overlays only: dialogs, context menus, banners
50%
only real circles: slider thumbs, knobs, dots

Icon tiles on the landing page are the one exception: 56px with 12px corners.

Type

  • UI: Segoe UI (--font), 14px/1.5 base; dense tools set the body to 13px. Labels 12px, hints 11-12px.
  • Numbers, values, codes, file names: Consolas (--mono).
  • Section headers: .section, 12px bold uppercase, .06em tracking, --muted, with a 1px line to the right.
  • Display: Cinzel Decorative only for the Daedalus name (landing page) and WIP tile initials.

Controls

ChipWIP
Row card
  • Buttons: --line fill, --hover on hover; primary = accent fill with --base text.
  • Toggles: on = accent fill (or the meaning color, e.g. record = --bad).
  • Tabs: transparent and --muted; on = --line fill with accent text. No pill container around them.
  • Range: flat 4px track; the thumb stays flush with both ends, and the fill reaches the thumb center (--p kept in sync by script).
  • Lists: one card or row card per item, one surface step away from the pane.

Tool identity

Each tool has one accent, equal to its icon's base color. Set it as --accent in the tool's :root.

  • Name: a Greek god or myth that fits the tool's job.
  • Icon: one simple back form (ring, hexagon...) with the tool's initial drawn on top, breaking through it with a gap cut around the letter. Flat, 1-2 colors, no outline. Athena's is the target style.
  • Files: <tool>/assets/<tool>.svg (tight viewBox) and .ico; used as favicon, header brand icon and landing tile.
  • UI icons: Font Awesome Free from the shared sprite (shared/icons/ → shared/icons.js).

Build

  • Static page, no build step: opens from file:// and runs on GitHub Pages.
  • Load order: shared/base.css, then the tool's style.css. The tool CSS adds its accent and layout and never redefines base tokens.
  • Plain UMD scripts (window.DAE in the page, module.exports in Node), so the CLI and tests share the core.
  • Files are TOON (JSON accepted on load).
  • Reuse shared/ before writing a helper: files.js (open / save / pick / folder export), store.js (IndexedDB autosave, recent lists), ui.js (slider fill), menu.js (right-click menu), viewport.js (pan / zoom), snap.js (snapping + guides, Alt for free), cli.js (CLI args and edit-op strings), handoff.js (open a file in another tool), markdown.js, ogg.js + opus.js (Opus files), history.js, toon.js, rng.js, icons.js, and DAE_CORE.worker(main) in core.js for file:// safe workers.
